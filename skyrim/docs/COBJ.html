COBJ records describe Constructible OBJects recipes, such as those used for Cooking, Smelters, Forges, Grindstones, and Workbenches. Constructible objects are used for both recipes that create new items, and recipes that improve existing items. The difference lies purely in the workbench keyword: different workbenches open different menus, and the menus will in turn handle the recipes differently.

It appears that COBJ records are keyed by Editor Id rather than Form Id, as the game will gladly load any number of records with a Form Id of 0x00000000.
