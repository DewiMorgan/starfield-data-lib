MSTT records contain information on movable static objects.

Record header flags:

0x100 - Must Update Anims
0x200 - not On Local Map
0x10000 - Random Anim Start
0x80000 - Has currents
0x2000000 - Obstacle
NavMesh Generation Import Option, at most one can be set, defaults to "Collision Geometry"
0x4000000 - Filter
0x8000000 - Bounding Box
0x40000000 - Ground
C SubRecord Name Type/Size Info
+ EDID editorId zstring Editor id
+ OBND object bounds OBND Object Bounds
- MODL model MODL Includes Fields MODT, MODS,
- DEST destruction data DEST Includes Fields DSTD, DMDL, DMDT, DSTF
+ DATA flags uint8 flags? values 0x00 through 0x03
- SNAM looping sound formID Ambient Sound (SNDR)
