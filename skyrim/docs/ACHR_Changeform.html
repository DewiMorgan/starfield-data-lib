ACHR change form

The ACHR change form contains information about actor instances, including but not limited to their:

  • Position
  • Inventory
  • Skill levels
  • Perks (Todo: check if accurate)
  • Spells (Todo: check if accurate)
  • Shouts (Todo: check if accurate)
